ESP32 Image Frame

Converts any photo to the 240×240 RGB565 image.bin the ESP32 displays.

  1. Download image.bin above.
  2. In this GitHub repo, replace the existing image.bin (Add file → Upload files → Commit).
  3. Wait ~1 minute for GitHub Pages to redeploy.
  4. The ESP32 picks up the new image automatically on its next poll.
